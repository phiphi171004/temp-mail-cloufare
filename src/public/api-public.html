TempMail Public API

Không cần API key. Hệ thống dùng X-Session-ID để tách phiên người dùng. Bạn chỉ cần gọi HTTP API và gửi header X-Session-ID.

Public API Không cần API key.
Mỗi user nên dùng X-Session-ID riêng để tách hộp thư. Nếu không gửi, hệ thống sẽ dùng session mặc định default.

Quick start

1) Get sources

Request
GET YOUR_ORIGIN/api-public/sources

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "sources": [
    { "id": "noopmail", "name": "NoopMail (noopmail.org)" }
  ],
  "current": { "id": "tmail" }
}

2) Domains (by source) + create + messages

Request A (lấy domains theo source)
GET YOUR_ORIGIN/api-public/domains?sourceId=noopmail

Headers:
{
  "Content-Type": "application/json"
}

Response (sample)
{
  "success": true,
  "source": { "id": "noopmail" },
  "domains": ["mmocommunity.io.vn", "ramcloud.us"],
}

Request B (tạo email)
POST YOUR_ORIGIN/api-public/email/create

Headers:
{
  "Content-Type": "application/json"
}

Payload:
{
  "sourceId": "noopmail",
  "username": "myemail123",
  "domain": "mmocommunity.io.vn"
}

Response (sample)
{
  "success": true,
  "email": "myemail123@mmocommunity.io.vn",
  "domain": "mmocommunity.io.vn"
}

Request C (lấy danh sách thư)
GET YOUR_ORIGIN/api-public/messages

Headers:
{
  "Content-Type": "application/json"
}

Response (sample)
{
  "success": true,
  "count": 2,
  "messages": [
    { "id": 21025, "subject": "Your login code", "sender_name": "VEED" }
  ]
}

Mục lục (theo số thứ tự)

  • 1. GET /api-public/sources
  • 2. GET /api-public/domains?sourceId=...
  • 3. POST /api-public/email/create
  • 4. GET /api-public/messages
  • 5. GET /api-public/message/:messageId
User chỉ cần dùng 5 endpoint public này. Khuyến nghị: gọi domains với sourceId bạn muốn trước khi create email.

1) GET /api-public/sources

Lấy tất cả nguồn mail (sources) đang có.

Request
GET YOUR_ORIGIN/api-public/sources

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "sources": [
    { "id": "noopmail", "name": "NoopMail (noopmail.org)", "isCurrent": false },
    { "id": "tmail", "name": "TempMail (mmocommunity.io.vn)", "isCurrent": true }
  ],
  "current": { "id": "tmail" }
}

2) GET /api-public/domains?sourceId=...

Lấy danh sách domain hỗ trợ cho source bạn chọn.

Request
GET YOUR_ORIGIN/api-public/domains?sourceId=noopmail

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "source": { "id": "noopmail" },
  "domains": ["mmocommunity.io.vn", "ramcloud.us"]
}

3) POST /api-public/email/create

Tạo email tạm theo username + domain (tùy provider).

Request
POST YOUR_ORIGIN/api-public/email/create

Headers:
{
  "Content-Type": "application/json"
}

Payload:
{
  "sourceId": "noopmail",
  "username": "myemail123",
  "domain": "mmocommunity.io.vn"
}

Response (sample):
{
  "success": true,
  "email": "myemail123@mmocommunity.io.vn",
  "domain": "mmocommunity.io.vn"
}
Provider như etempmail có thể cho phép username null (random) nhưng tùy từng nguồn.

4) GET /api-public/messages

Lấy danh sách thư trong hộp thư của email hiện tại.

Request
GET YOUR_ORIGIN/api-public/messages

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "count": 2,
  "messages": [
    {
      "id": 21025,
      "subject": "Your login code",
      "sender_name": "VEED",
      "sender_email": "noreply@login.veed.io"
    }
  ]
}

5) GET /api-public/message/:messageId

Lấy chi tiết nội dung thư.

Request
GET YOUR_ORIGIN/api-public/message/21025

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "message": {
    "subject": "Your login code",
    "from": "noreply@login.veed.io",
    "content": "<html>...</html>"
  }
}
