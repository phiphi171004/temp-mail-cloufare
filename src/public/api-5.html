TempMail Public API (5 endpoints)

Không cần API key. Mỗi user dùng X-Session-ID để tách hộp thư. Các endpoint public dùng namespace /api-public.

X-Session-ID là do client tự tạo (thường generate 1 lần rồi lưu localStorage). Ở trang test này, nếu bạn để trống thì nó sẽ tự sinh một ID và điền vào ô đó.

Base URL → YOUR_ORIGIN Header → X-Session-ID
Origin: Current email: — Messages: 0 Status: Ready
Mục lục
  • GET /api-public/sources
  • GET /api-public/domains?sourceId=...
  • POST /api-public/email/create
  • GET /api-public/messages
  • GET /api-public/message/:messageId

1) GET /api-public/sources

Lấy tất cả nguồn mail (sources) đang có.

Request
GET YOUR_ORIGIN/api-public/sources

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "sources": [
    { "id": "noopmail", "name": "NoopMail (noopmail.org)" }
  ],
  "current": { "id": "tmail" }
}

2) GET /api-public/domains?sourceId=...

Lấy danh sách domain hỗ trợ cho source bạn chọn.

Request
GET YOUR_ORIGIN/api-public/domains?sourceId=noopmail

Headers:
{
  "Content-Type": "application/json"
}

Response (sample):
{
  "success": true,
  "source": { "id": "noopmail" },
  "domains": ["mmocommunity.io.vn", "ramcloud.us"]
}

3) POST /api-public/email/create

Tạo email tạm theo username + domain (tùy provider). Sau khi create, session sẽ có “current email”.

Request
POST YOUR_ORIGIN/api-public/email/create

Headers:
{
  "Content-Type": "application/json",
  "X-Session-ID": "optional"
}

Payload:
{
  "sourceId": "noopmail",
  "username": "myemail123",
  "domain": "mmocommunity.io.vn"
}

Response (sample):
{
  "success": true,
  "email": "myemail123@mmocommunity.io.vn",
  "domain": "mmocommunity.io.vn"
}

4) GET /api-public/messages

Lấy danh sách thư trong inbox của email hiện tại trong session.

Request
GET YOUR_ORIGIN/api-public/messages

Headers:
{
  "Content-Type": "application/json",
  "X-Session-ID": "optional"
}

Response (sample):
{
  "success": true,
  "count": 2,
  "messages": [
    {
      "id": 21025,
      "subject": "Your login code",
      "sender_name": "VEED",
      "sender_email": "noreply@login.veed.io"
    }
  ]
}

5) GET /api-public/message/:messageId

Lấy chi tiết nội dung một message theo messageId.

Request
GET YOUR_ORIGIN/api-public/message/21025

Headers:
{
  "Content-Type": "application/json",
  "X-Session-ID": "optional"
}

Response (sample):
{
  "success": true,
  "message": {
    "subject": "Your login code",
    "from": "noreply@login.veed.io",
    "content": "<html>...</html>"
  }
}
